1. NEW FILE: app/src/main/kotlin/com/jarvismini/agent/VoiceIntentRouter.kt
   -----------------------------------------------------------------------
   Purpose: single entry point that decides whether user text (typed or
   future voice/STT input) is ordinary chat or a real action for Agent J.

   Classification is two-tier:
     a) Fast keyword pass — zero cost, no model call.
        - ACTION_VERBS list ("open ", "apply ", "send ", "fill ", "block ",
          "close ", "install ", "message ", "call ", "launch ", "toggle ",
          "turn on/off ", "automate ", etc.) -> instant Task classification.
        - CHAT_MARKERS list ("what is", "who is", "explain", "thanks",
          "hello", etc.) -> instant Chat classification.
     b) LLM fallback — only for ambiguous phrasing that doesn't hit either
        list. Reuses the EXISTING on-device LlamaLLMEngine.generateReply()
        — no new model/dependency added. Prompt forces raw-JSON-only output
        {"intent": "chat"|"task", "task": "..."}; extractJson() strips
        markdown fences defensively in case the model doesn't comply.
        Falls back to Chat on any parse/model failure — never throws, never
        silently drops a message.

   Device targeting:
     - defaultDevice() reads JarvisPrefs.getString("agent_device") first,
       falls back to a hardcoded default only if unset.
     - Verified against agentJ.txt (agent_server.py) that Phone A's ADB
       port has already changed at least three times across sessions
       (40657 in app defaults -> 41367 hardcoded in agent_server.py ->
       35253 current per memory). Confirms the pref-based approach is the
       right call instead of hardcoding.

   Execution:
     - routeAndExecute(input, onChat, onTaskStarted, onTaskResult,
       onTaskFailed) is the single call site. On Task classification it
       calls the REAL AgentRepository.runTask(task, device) — verified
       this matches agent_server.py's actual POST /run contract
       ({"task", "device", "max_steps"}) — and AgentRepository.speak() for
       a spoken acknowledgement. No mocked calls anywhere in this file.
